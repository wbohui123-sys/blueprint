# Blueprint

从用户意图到可用产物的多节点 AI 工作室。节点按测量与分工两条原则工作，走完粗略估计、经验粗评、取材评估、校准定稿四环，再执行取得实际结果。复杂工作分成各有合适 context 的节点，项目、过程、文件和成果集中在同一个窗口。

第一版支持 macOS Apple Silicon。桌面应用内置 Node 和必要的 DeepSeek Harness 引擎，使用者无需安装 DSH、Node 或包管理器。

文件廊的视频缩略图和音频频谱使用随应用附带的独立 FFmpeg，启动时检查是否可运行，不依赖用户 Homebrew 的 FFmpeg／x265。对应源码、构建参数与许可证一并随包提供；其他视频制作与转码工具仍可使用用户自行安装的 FFmpeg。

桌面图标源为 `desktop/blueprint-icon.svg`，对应的 1024px PNG 保留透明安全边和黑色圆角轮廓，无白色底板、描边或阴影。打包从这份独立 PNG 生成各尺寸 ICNS，网页 favicon 沿用原资源。 macOS 26 可能再给传统 ICNS 加材质外框；本机无亮边外观可通过系统自定义图标设置应用。该设置保留普通代码签名验证，但会增加 Finder 图标元数据，因此发布包仍保持未附加本机覆盖的严格签名状态。

## 使用

当前桌面窗口打开与 `./dsh web` 相同的 dsh 根界面，加载 base、web-app、Blueprint 三层 bundle。图纸、看板和品牌随 Blueprint bundle 加载。以下旧版界面操作说明仍可在 `/studio/` 对照；新项目表单、Brief 和 Blueprint 专用技能面板本段尚未迁入新窗口。

打开 Blueprint，在右上角的连接管理中填写自己的 API 地址、Key 和模型，选择默认模型，然后新建项目。模型服务的费用由所选服务商收取。

设置齿轮旁边的问号是帮助（首页在顶栏齿轮左边，进了项目在左窗竖栏齿轮上面）：设置看不懂、API 不会加、哪里报错、想装插件，都可以直接问。它是一条普通的 dsh 会话（cordis 预设，不设沙箱、不弹确认），工作目录是数据目录里的 `助理/`，读那里的 `AGENTS.md`（原文在 `prompt/助理/AGENTS.md`）；用同一个模型连接，费用照算。还没连模型时，点开先引去连接模型。

新建项目的 Brief 可通过「插入文件 / 图片」、拖入文件或粘贴图片添加参考材料，图片显示缩略图，附件可移除。最多 20 个文件、合计 20 MB；创建失败保留草稿，成功后附件保存到项目的 `素材/Brief/`，文件引用进入初始需求，节点开始工作前即可读取。

节点对话可点击左下角「＋」添加文件或图片，也可拖入文件、粘贴图片；图片和文字一起粘贴时都保留。文字与附件草稿按节点保存，切换回来可继续发送。节点可只读访问自己或同项目上级已收到的附件原件，需要修改时先复制到项目目录。

新项目默认 max 品质与 spark 模式。spark 用于一起构思尚不明确的目标，build 用于已有大致目标、执行方案需要共同判断的工作，solo 由节点自主推进。当前选择继续保留；旧 co-create 与 execute 按目录迁移为 build，旧 solo 保留。模式说明与引导由 prompt 包的协作模式目录提供。

模型失败直接显示“响应超时”或“接口限流”，等待与开始自动重试各有可见记录。所有模型连接的默认重试冷却约 10、20、40 秒，之后最多 60 秒再试，最多重试五次；新连接与升级后尚未设定策略的旧连接采用此值，已有自定义策略保留。

在 API 管理中选择图片、视频、音频模板，填写基础地址与 Key，添加模型并勾选它实际支持的用途。已保存的媒体服务供所有节点按任务自主发现和调用，包含生成、理解与音频转文字；可处理本项目文件和当前会话上传的媒体附件。生成候选保存在项目的 `.blueprint-tmp/生成/`，保留生成说明；选中的由 `shelve` 上架到 `素材/`，附为什么拿、用途与来源，生成检索目录和内页。异步视频任务可在重启后继续查询，已上架文件仍可按原任务查询。媒体调用按对应服务商计费，接口返回的用量保存在本地任务回执；顶部费用汇总目前仍来自对话模型账本。

第一版适配 [OpenAI 媒体接口](https://developers.openai.com/api/reference/resources/images)、[Gemini generateContent](https://ai.google.dev/api/generate-content)、[fal 队列接口](https://fal.ai/docs/documentation/model-apis/inference/queue) 和 [硅基流动图片接口](https://docs.siliconflow.cn/docs/api/images-generations-post)。硅基流动模板预填 `Tongyi-MAI/Z-Image-Turbo`，默认 `image_size: "1280x1280"`；支持参考图的其他图片模型也经同一 JSON 端点调用。返回的临时图片地址会立即下载，取图失败可按同一任务重试，不重新生成。硅基流动的视频、音频专用协议尚未适配。其他服务商使用相同协议时可填写自己的地址与模型；专用协议需要增加适配器。媒体直接输入合计上限为 20MB、每次最多 8 个文件，超过时先压缩或截取相关部分。

`draw` skill 保留画面准备与成果检查的方法，在有媒体工具时从 API 目录选择服务，再通过 `media_call` 生成或编辑；旧环境没有媒体工具时仍可使用随附脚本。API 连接负责地址、模型能力与 Key，skill 负责如何取得适用的图片。个人 Key 只存本机，不进入发布源码或安装包。

关闭窗口后任务继续运行；应用菜单里的“退出 Blueprint”停止执行并保存过程。重开后停在项目首页，从最近项目或「全部项目」打开原项目，使用 Start All 继续。更新或替换应用不会删除用户数据。

节点需要回答问题或确认操作时，通过 macOS 通知中心发出提示音和系统提醒，显示项目与节点；点击通知打开对应节点的 Chat。App 在前台或正在查看提问节点时，新问题仍会提醒；桌面版使用系统提示音，浏览器版使用页面提示音。窗口关闭后仍能接收，应用退出后停止接收。打开节点即清除该节点已有的角标和通知，无须先回答；问题和操作确认仍保留，查看不等于答复或批准。已读状态随原问题保存，重启与重连不重复提醒。启动时未查看事项合为一条提醒，Dock 角标显示未查看数量。第一次收到系统授权提示时选择允许；也可从 Blueprint 菜单选择“发送测试通知”或“打开通知设置”。

App 每次打开都停在项目首页，不自动进入上次的项目；首页内容在窗口中居中。

macOS 的关闭、最小化和全屏按钮在顶栏左上，Logo 与其余顶栏内容向右让出这块位置；拖动顶栏空白处移动窗口，Logo 和按钮照常点击。桌面外壳在页面根元素设 `data-blueprint-desktop`，不设 dsh 的 `data-platform`（后者表示 dsh 官方桌面壳，会要求它的键盘桥接）。

数据目录为 `~/Library/Application Support/Blueprint 新版/`。1.0 从空白数据开始，不读取、不迁移旧版的 `Blueprint/` 文件夹，旧版数据原样留在那里。项目位于其 `项目/` 下，prompt 和 skill 的可编辑副本位于 `prompt/`，引擎记录位于 `engine/`。菜单可以打开数据目录和日志。默认内容升级保留个人修改，新默认值另存于 `默认更新/`；新版里撤下的默认文件，没改过的直接删掉，改过的挪到 `默认更新/退役/`，都不留在 `prompt/` 里被模型读到。

模型的运行环境提供项目根、原生当前工作目录与可写临时目录，路径由实际安装和用户数据位置取得。文件、搜索和命令的相对路径以当前工作目录为基准；`working_directory` 切换该 Session 的目录，`workdir` 仅指定该次命令的目录。项目身份、节点文档和归档仍属于原项目，切目录或重启不会改变归属。目录包含中文或空格时也沿用同一机制。

从 Finder 启动也搜索当前用户的 `~/.local/bin` 与 `~/.npm-global/bin`，内置 Node 优先；不继承外部 `NODE_PATH` 或 `NODE_OPTIONS`。项目命令的 uv 缓存、下载的 Python 和 matplotlib 配置放在各自项目的临时目录，素材搜索不会自行恢复已被隔离的系统代理。

文件、搜索、命令、问答和节点协作使用内置引擎。新建项目的 Skills 区通过办公、游戏、设计、视频、小说、3D、文档七个任务类型按钮直接搭配技能，悬停可看工作目标；每类都有自己的组合。展开后分为「已选技能」与「未选技能」两组，勾选或取消让卡片在两组之间移动，数量同步更新；支持全选、清空与恢复默认。名称与原 skill ID 同行，下方保留短用途和依赖条件；调整入口与批量操作同行，项目保存状态放在顶行。初始不选任务类型，沿用全局默认；切换类型替换组合，切回办公也应用其独立组合，重复点击当前类型保留手动调整。「恢复默认」返回全局默认并取消类型高亮，切换类型不改 Brief。选择对所有节点生效，正文仍按需读取。粗略估计、经验粗评、取材评估与实际执行的 skill 属于节点本体，始终可读，不在可选 Skills 面板里；校准定稿通过 strategy 完成。项目内的 skill 面板可随时调整本项目选择，保存在 `系统文档/技能.json`；没有单独选择的旧项目沿用全局开关，未打开项目时的开关决定新项目默认值。

skill 面板区分已启用和当前条件：缺少程序、媒体 API 配置、尚未接入的能力分别说明原因与下一步。模型每步重新检查，只收到本项目已启用且满足条件的 skill；安装依赖或修改 API 后不需重启。依赖目录在 `prompt/能力依赖.json`，新增同类能力只需声明条件。命令检查确认可执行文件存在，服务检查确认配置与 Key 来源，不代表已经实测版本、网络或生成效果。

办公与文档预设包含官方 Word、Excel、PowerPoint 技能，使用随包 Python 与 LibreOffice Kit；源码版从 bundle 的实际目录定位资源。办公预设同时负责资料取得、多格式读取、数据处理与图表说明。游戏预设同时提供 Godot 2D／3D 工程和随工程分发的 Phaser 网页 2D 游戏；3D 预设提供 Godot 实时场景与 Three.js 网页模型展示，技能摘要按交付环境区分用途。小说预设分别处理章节材料与叙事状态、作者文风与改稿对照。视频预设提供本地 HTML 时间轴动画，完整 MP4 导出和音轨混合尚未接入。文档预设负责办公材料读取、数据与图表、可编辑 PPTX 和报告排版，沿用原 `more` 类型 id。设计资料统一保留 OpenDesign，界面评审与打磨使用 Impeccable，并提供素材复用。共享工具供多个情境复用同一入口；旧项目选择中的 `ui-ux-pro-max`、`explainroo` 分别按 `open-design`、`html-video` 读取，重复入口撤下，原来的辅助资源保留。

ImageMagick、FFmpeg、uv、Poppler 等仍需对应外部程序。项目启用浏览器能力后，通过官方 Playwright MCP 使用随包无头浏览器进行页面导航、输入、点击与读取；控制其他桌面 App 尚未接入，不引导用户授予整机操控权限。内置预览、媒体播放与网页截图不需要屏幕录制或辅助功能权限。可用性检查保留用户 skill 开关，不修改项目或 API Key。

浏览器 MCP 与其子进程统一继承 Blueprint 项目 Seatbelt，限制邻居项目、宿主账本、个人文件夹及宿主管理端口；项目内机器维护文件仍禁止写入。浏览器状态和快照保存在项目 `.blueprint-tmp/browser/`，短 Unix socket 目录随能力释放。macOS 不允许受限进程再应用 Chromium 的另一份沙箱策略，因此此入口显式关闭 Chromium 内层沙箱；这是项目级隔离，不具备 Chromium 原有的进程间沙箱隔离能力。

所有模型共用同一个 `web_search` 工具，通过 DuckDuckGo 公共搜索页面取得网页标题、链接和摘要，无需搜索 Key 或模型厂商的联网开关。换模型、添加 API 连接均不影响搜索；当前模型负责提出查询、阅读结果，并按需用 `web_fetch` 读取原文。只返回真实搜索来源，结果随原生工具记录保存。公共搜索服务的验证、限流或网络失败会明确报错，不把错误页面当成无结果。

网页抓取兼容 TUN 代理的 Fake-IP 解析：仅当系统 DNS 返回 `198.18.0.0/15` 路由地址时，通过 HTTPS 公共 DNS 获取真实地址，再沿用引擎的公网检查和固定地址连接；内网地址、超时、正文大小和重定向限制仍由引擎处理。

项目文件预览使用独立的 `localhost` 来源和只读预览凭据，网页与相对脚本、样式、图片共用路径凭据。预览不依赖主界面的跨站 Cookie；凭据只适用于指定会话的项目文件，不能访问设置或操作 API。重启后旧预览地址失效，从 App 重新打开文件即可取得新地址。

左侧直接查看 HTML、PDF、常见图片和 Markdown／文本及源码，音视频使用原生播放器，可播放、暂停和拖动进度；预览服务以流和字节范围读取大文件。MP4、WebM、MOV、MP3、WAV、OGG、M4A 的实际播放取决于内置浏览器支持的编码，不支持时可点“用系统打开”。办公文件、演示和应用沿用系统默认应用，不安装额外转换器；其他格式可定位原件。

任务廊可切换「阶段产物」「已上架素材」「过程文件」「查看与取得的材料」。两列卡片以上方 16:9 内容预览为主体：图片、视频、网页显示缩略切片，音乐显示前 30 秒频谱，文档与目录显示正文或条目信息；底部单行名称旁常驻「打开」「引用」，引用直接复制 Markdown 链接。预览按可见区域读取，首次成功生成后保存到应用的 `.dsh/任务廊预览缓存/`，换节点、重复打开和重启都复用已有结果；本地文件改变时更新，远程网页不定时重新抓取。视频与频谱在桌面安装包中使用内置的独立 FFmpeg，源码开发沿用本机 `ffmpeg`；网页使用内置浏览器。素材和过程文件是项目共享目录，点击目录才读取下一层，每页 60 项。过程文件包含 `.blueprint-tmp/` 和 `.blueprint-evidence/`；查看记录包含节点成功读取的文件及检索来源，可以选择当前节点、下属或整个项目。context 单条记录展开后，可点「查看这条记录的材料」查看对应文件和来源。材料入口只读现有文件与记录，不注入模型消息，不唤醒节点；不支持内置预览的格式仍保留定位入口，已删除或未保存的远程材料无法还原原件。

`render_page` 使用随 App 分发的浏览器，把项目 HTML／SVG 或公开 HTTP(S) 网页截为项目内 PNG，随后用 `read_image` 检查。截图不依赖电脑另装的 Chrome、Playwright 或 Node，不需要屏幕录制或命令全权限；原有命令与项目隔离保持生效。浏览器使用独立临时会话，按 DOM 启动与指定等待时间截图，不等待持续连接结束。外部网页和资源经公网地址校验与固定 IP 代理，不能访问宿主服务或其他项目。旧版“截.mjs”入口会提示改用内置工具。

节点在命令里自己开 Chrome（脚本写死正式版路径、bash 里的 `chrome`）时，改用随 App 分发的无头专用版 chrome-headless-shell，并让它用显卡画。用户电脑上不必装 Chrome；正式版 Chrome 每次启动都会叫醒 Google 更新程序，节点一天开几十次会堆出上百个进程，无头专用版不会。它在运行包的 `native-resources/browser/` 里，安装包约多 88 MB；`prepare:runtime` 按固定的 Playwright 版本取得，本机已有就不下载。bash 命令里直接写正式版 Chrome 的完整路径时仍会开正式版。

项目 HTML 登记暂停时间轴时，`render_page.time` 可指定动画秒数并取得可重复的画面；普通页面不填此参数。`look` 的可选像素比较复用 ImageMagick 7，保存变化区域、红色叠图和输入指纹。

每个节点的工作文档有请求、职责、结构、记录四段。节点用 `node_doc` 查看文档，更新自己的职责、追加记录；校准定稿：自己做用 `next` 交方案，分工用 `divide` 提交定稿后派人，节点之间用纸条沟通。派完人这一轮就停，孩子全部交回或收到纸条时醒来；接续承接前三段，记录留在前轮。

项目有两张机器维护的地图：节点总表和素材检索目录。前者显示谁在做什么、纸条往来，后者从素材组的说明卡片查入口，组内通过缩略拼版、视频抽帧、工程文件树和文档标题目录找原件。取素材的活由 run 节点照请求做完交回。

节点在自己的 Git 空间里做产物：主仓库在 `作品/`，其他节点的 worktree 在 `作品空间/`。机器创建空间，派出新节点前和交回时各提交一次；合并通过普通 Git 操作完成。从等待或阶段成果报告醒来时，原生压缩后端按四段文档、未回纸条与入口重建 context；工作中 context 太大时，保留最新文档、历史续工摘要和最近完整步骤。原始会话仍可查看。系统规则改动后需重启源码服务；安装版需要重新打包更新。

`create_worktree` 采用官方服务，从当前 Git checkout 的本地提交创建自主分支并进入 `.agents/worktrees/<名称>/`；需要 Git 2.45 或以上。它不复制未提交修改，不替代正式节点空间或交回提交。需要纳入正式成果的内容沿普通 Git 操作整合。当前目录保存在原生会话中，检出目录消失时回到原项目；工作树的普通产物可展示、预览和截图，Git 管理文件与隐藏配置不提供网页预览。

## 从源码运行与打包

在 Apple Silicon Mac 上使用 Node 22.19 或以上版本。以下命令在仓库根目录执行：

```sh
npm --prefix app ci
npm --prefix app start
```

生成应用目录或安装文件：

```sh
npm --prefix app run pack
npm --prefix app run dist
```

## 结构

`blueprint/packages/` 保存系统的七个部件，`viewer/` 保存界面，`app/desktop/` 是桌面窗口，`app/runtime/` 是固定的运行装配，`app/scripts/` 管准备、检查和发布。引擎版本及多模态补丁随应用一起固定；应用运行时不安装插件或依赖。

Blueprint 自己的源码以 GNU AGPL-3.0（仅第 3 版）发布，全文见 `LICENSE`：可以自由使用、修改和分发；分发修改版或拿它提供网络服务时，须以同一许可公开对应源码。上游及随附组件各按原许可，声明见 `app/THIRD_PARTY_NOTICES.md`。精简导出目录与安装包不含用户 Key、私人项目、历史账本或研究原料。

`npm run smoke:context` 用隐藏浏览器核对节点文档更新的默认折叠、原文展开与实时／历史一致，不调用模型或读取屏幕。

节点 preset 的原生压缩后端是 `@blueprint/node/compaction`，默认 `thresholdTokens: 300000`，由原生 tokenMeter 实际测量。中途压缩保留近期 `retainTokens: 40000` 的原文，边界扩展到完整步骤；历史续工摘要通过原生 LLM 服务生成，上限 `summaryMaxTokens: 8192`。`app/runtime/backend.mjs` 按各包的 `package.json` exports 解析入口与子路径，独立宿主也能加载该后端；实现与部署接线见 node 包和共用的 `blueprint/agent.cordis.yml`。

原生冷读优化固定于 `0.2.1-alpha.2`：`native-read-patch.mjs` 核对并安装 `native-read-0.2.1-alpha.2.patch`，源码启动、CLI 准备与 App 资源准备共用。补丁合并同时进行的历史目录观察，以最多 16 份会话头并行读取、按原顺序校验与返回；会话头按文件身份记住，每次列举仍逐个 stat、身份一变即重读；目录与按 ID 查账本并行探，`list()` 用同一次观察算语料版本。迁移前后的子会话成员与正文版本校验保留。调用者独立取消，全部退出才取消共享扫描；原错误、重复 ID 检查与只读行为不变。版本或补丁接缝不合则停止安装，资源清单记录补丁签。

预览读取恢复固定于 `0.2.1-alpha.2`：`preview-read-recovery-patch.mjs` 核对并安装同名补丁，源码启动、CLI 准备与 App 资源准备共用，资源清单记录补丁签。图片等完整字节预览的单次读取超过 15 秒就取消并重试一次；再次超时，原生预览退出加载、显示“文件预览读取超时，请重试”和原重试入口。关闭页签或手动刷新即清理旧请求和定时器，迟到结果不覆盖新图。明确的文件错误沿原逻辑显示。此补丁处理读取悬挂，不证明长时间运行后的最初触发原因已解决。

工具参数修补固定于 `0.2.1-alpha.2`：`tool-json-repair-patch.mjs` 核对并安装 `tool-json-repair-0.2.1-alpha.2.patch`，源码启动、CLI 准备与 App 资源准备共用。DeepSeek 写坏的工具参数在块结束时先修补：字符串里的真换行等控制字符转义；字符串或括号到结尾没收，就补上引号和括号，没收的字符串以多出来的右括号结尾时那个括号算结构；整个对象收完后又多写右括号的，去掉多的；最外层中途提前收了、后面接着逗号写下一个键的，去掉提前收尾的括号和多的右括号，键接回最外层（后面接的不是逗号就不动）；中途写了一个对不上任何开着的括号的右括号（收了 plan 又多写一个 `]`），去掉它，对得上更深一层开括号的不猜。改补丁后已装的引擎要先用旧补丁反向卸掉再装新的。修好的必须是对象。修不好的，整步仍按 `MALFORMED_RESPONSE` 退回，报错首行之后一个坏调用一行：工具（`call_tool` 带内层名）、文件、解析错误、附近原文；出错重试据此填 `重置/叫醒/工具参数坏了.md`。截断（max-tokens）照旧由组装器整批丢弃工具调用。版本或补丁接缝不合则停止安装，资源清单记录补丁签。

项目与存储：新用户默认把项目保存在系统文稿目录的 `Blueprint/项目/`。设置与新项目页可查看并更改位置，首页直接使用默认位置；新项目页的保存位置位于项目名称右侧，桌面版使用系统文件夹选择器。更改只决定之后新建的项目，旧项目保留原路径并继续显示；应用配置、会话账本和日志仍保存在应用数据目录。测试脚本单独指定临时项目位置，不使用真实用户文稿目录。

首页开场动画只在首次使用时播放，自然结束或主动跳过后将完成标记保存到应用数据目录的 `首页动画.json`。刷新、关闭窗口再打开和完整重启 App 都读取同一份记录，随机端口变化不触发重播；未播完直接关闭不算完成。
